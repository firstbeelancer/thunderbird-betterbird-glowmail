# AGENTS.md — GlowMail (тема для Thunderbird / Betterbird)

Маленькая тема, дорабатывается потихоньку, неспешно. Проект в TigerWiki для неё не заводить.

## Главное правило — никаких ключей

Ни в коем случае никаких ключей в репозитории: ни API-ключей, ни токенов, ни паролей, ни секретов, ни приватных ключей, ни PAT, ни `.env`, ни чего-либо подобного — ни в файлах, ни в коммитах, ни в issue, ни в PR, ни в комментариях, ни в скриншотах.

Это касается и проверки этой публикации: перед каждым коммитом и перед каждой публикацией проверить содержимое — прогнать поиск по ключам/секретам и убедиться, что ничего не утекло. Если ключ где-то появился — не публиковать, остановиться и сказать Марине, ключ отозвать.

## Что где лежит

- Источник правды — `theme/`: `manifest.json` и `chrome/userChrome.css`. `public/download/` — копии, держать в синхроне.
- Стенд-спецификация — Vite + React 19 (`src/`, `index.html`). Токены цветов — в `src/lib/tokens.ts`, они же в `userChrome.css` и `manifest.json`.
- Палитра: панель папок `#0F1A17`, акцент `#2EE6A8 → #22D3EE`, список/письмо белые, WCAG AA.

## Не выдумывать

- Шрифты Inter (`theme/chrome/fonts/Inter-*.woff2`) в v1.0 отсутствуют — не подменять другими файлами и не генерировать фейковые. Добавлять только настоящие файлы, когда Марина их даст.
- Не менять версию и `manifest.json` без её слова. Мелкие правки — маленькими шагами, с проверкой.
