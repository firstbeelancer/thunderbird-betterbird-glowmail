# GlowMail — что представляет собой тема (обзор стенда)

Стенд-спецификация темы: живой макет, состояния, контраст, решения, установка, приёмка.
Оригинал стенда: https://01a1c441-080d-7406-88db-5c826937426c.arena.site/

## Идея

Тёмная панель папок с мятно-бирюзовым свечением, светлый список писем и письмо.
Метки читаются с первого взгляда, контраст проверен по WCAG AA.
Thunderbird 128+ · Betterbird · v1.0.

## 01 · Живой макет — три панели: папки, список, письмо

Папки: Входящие (12 непрочитанных из 248), Черновики, Отправленные, Архив, Спам, Корзина, Работа, Семья — у каждой свой цвет иконки.
Письма (демо): макеты главной от Анны Власовой, платёж до 18:00, план релиза 2.4, договор подряда, переезд на CI, фото с корпоратива, спам «ВЫ ВЫИГРАЛИ!», Frontend Weekly.
Переключатели макета: вид списка (карточки / таблица), плотность (компактная / обычная / просторная), фокус в списке, масштаб 100–150%.

## 02 · Состояния для приёмки

Каждое состояние — отдельной карточкой с кодом (S01, F03, T02…): непрочитанное, избранное, важное, ветки, вложения, ответы/пересылки, спам, теги. Эталон для сверки скриншотов из живого Thunderbird.

## 03 · Окна и элементы

Написание письма, адресная книга, меню, диалоги — та же стилистика: акцентная кнопка действия, тёмные списки источников, белые рабочие области, заметные рамки полей.

## 04 · Контраст WCAG AA

Проверка всех пар цветов по формуле WCAG из реальных токенов. Текст ≥ 4.5:1, иконки/рамки ≥ 3:1. Честно отмечено: чистый `#F5B700` даёт 1.7:1 на `#FFF8E1` — поэтому у звезды добавлен тёмный контур `#7A5600` (6.3:1).

## 05 · Решения по открытым пунктам

- Вид списка — карточки: помещаются отправитель, тема, превью и тег, полоски и точка-маркер читаются лучше таблицы.
- Плотность — обычная (≈64 px карточка); компактная режет превью на 125–150%.
- Тёмный режим системы — светлая тема всегда (`color_scheme: light`); тёмной остаётся только панель папок и рамка. Отдельная тёмная версия — следующий этап.
- Избранное + важно — две полоски: красная (4 px, внешняя) и жёлтая (4 px, рядом).

## 06 · Установка

1. Тема (.xpi): Дополнения и темы → установить из файла → `glowmail-theme.xpi` → Включить.
2. Разрешить userChrome: `toolkit.legacyUserProfileCustomizations.stylesheets = true`.
3. Папка профиля → создать `chrome/`, скопировать `userChrome.css` и `fonts/`.
4. Перезапуск Thunderbird; если не подхватилось — запуск с `-purgecaches`.
5. Вид списка — карточки, плотность — обычная.

Подпись: релизный Thunderbird принимает только подписанные `.xpi` (addons.thunderbird.net, временная загрузка через `about:debugging`, или `xpinstall.signatures.required = false` на Betterbird/ESR).
