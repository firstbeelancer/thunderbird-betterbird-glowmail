# Установка GlowMail

1. Скачай файл `glowmail-1.3.1.xpi` или нажми **glowmail-theme.xpi** на стенде.
2. В Thunderbird или Betterbird нажми `Ctrl+Shift+A`, чтобы открыть **Дополнения и темы**.
3. Нажми шестерёнку справа вверху → **Установить дополнение из файла…**. Выбери скачанный XPI и подтверди установку.
4. В разделе **Темы** проверь, что GlowMail включена. Полностью закрой почтовую программу и открой её снова.

XPI содержит стили, иконки и шрифт. В Betterbird 153 пакет устанавливается из файла с настройками дополнений по умолчанию.

Если раньше GlowMail ставилась вручную, профильный `chrome/userChrome.css` может перекрывать правила XPI. Проверь старый блок выделения, если строка открытого письма осталась мятной.

Переключатель «день–ночь» в шапке письма управляет штатным режимом чтения Betterbird. В дневном режиме фон письма белый.

Чтобы удалить тему, открой **Дополнения и темы → Темы → GlowMail → … → Удалить**.
